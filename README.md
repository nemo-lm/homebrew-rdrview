# Nemo-lm Rdrview

## How do I install these formulae?

`brew install nemo-lm/rdrview/<formula>`

Or `brew tap nemo-lm/rdrview` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nemo-lm/rdrview"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
